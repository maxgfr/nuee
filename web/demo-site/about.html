How it works

  1. nuee site publish ./public --on <group> --name blog encrypts the folder and gives it a link that stays the same across versions.
  2. The group's keepers copy it. When one dies, another takes over.
  3. nuee site loader writes three files for any static host. They fetch the site, check it, and serve it from that host's address, scripts included.
